# 轻笺

一个本地优先的 Windows 桌面便签工具。基础功能零第三方依赖，语音转写为可选组件。

- 普通用户请阅读：[使用说明.md](使用说明.md)
- 开发和功能规划请参阅：[PRD.md](PRD.md)

## 已有功能

- 多便签，新建、编辑、删除并自动保存
- 提醒、便签、笔记三个一级工作区
- 独立提醒与统一提醒中心
- 新闻页含 AI HOT 日报与免费模型快讯。AI HOT 在北京时间 08:00 切换；免费模型快讯在 09:00 后首次打开时更新，均使用单文件缓存覆盖前一天内容
- 便签单次提醒，笔记单次／每天／每周提醒
- 提醒完成、稍后30分钟、打开来源
- 双历月历选择器：阳历、农历、二十四节气、传统节日
- 2026年法定放假“休”和调休“班”标记
- 月历中查看当天提醒
- 笔记分类、标签、分类筛选和全文搜索；分类栏与现有笔记自动同步，同分类历史标签可直接复用及分类内重命名
- 笔记“AI面试复盘”：面试摘要、问答与STAR案例、不足与下一轮准备
- 笔记“AI会议总结”：会议纪要、决策与行动项、风险与待确认事项；缺失负责人或期限统一标记为“待确认”
- 笔记工具栏提供独立“录音”入口，只负责双轨录音、导入音频与 SenseVoice 转写；转写完成后可进入面试复盘或会议总结
- 每篇笔记的编辑窗口可直接选择“面试复盘”或“会议总结”，保存当前修改后再按对应模板分析
- “AI面试复盘”内支持分别录制麦克风与 Windows WASAPI 会议声音，停止录音后使用本地 SenseVoice-Small 转写
- 录音窗口提供准实时“面试提问助手”：仅分析会议方音轨，本地端点检测在停顿约0.8秒后提交完整语句，连续讲话单段最长15秒并保留4秒音频重叠；提问上下文保留最近60秒或10句话并自动消除重叠识别文本。检测到末尾疑问句后立即开放“发送给AI”，同时在后台检索程序目录下的“面试知识库”。正式回答只调用一次Step，由同一次请求结合末尾疑问句、完整上下文和命中片段理解问题并生成答案。实时回答不读取任何轻笺笔记正文；知识库未命中时允许使用通用知识回答。AI回答按100至250字的口述长度生成并实时流式显示，状态栏分别显示ASR、知识库检索、AI首字及完整生成耗时。实时回答不设置过小的输出Token硬上限；Step只返回推理而无正文时自动重试一次
- 会议声音来自当前耳机或扬声器的回环端点，戴耳机时也可捕获；界面持续显示红色录音状态与计时
- 支持导入既有音频进行本地转写，转写结果可追加到当前笔记或生成独立笔记
- 每月、每年、工作日、指定星期、间隔、提前和截止日期等高级提醒规则
- 笔记连续学习、本周／本月／累计次数与积累日历
- Windows系统通知，失败时回退应用内提醒
- Windows系统托盘、关闭到托盘和托盘快捷新建
- 当前用户级开机启动
- 320×420紧凑模式，窄窗口下列表可折叠
- 各板块操作卡片按当前数量等宽分布，窄屏自动使用短标题
- 伴随式快捷边条：将提醒、便签或笔记拖到窗口侧边固定，右键可移除
- 单实例运行，重复启动只会唤起已运行窗口
- 新闻支持按栏目浏览摘要、刷新、打开 AI HOT 和第三方原文
- 免费模型快讯由 GitHub Actions 每天汇总 OpenRouter 当前免费 API 与 Hugging Face 近期开放权重模型，并覆盖固定 Release 中的 `daily.json`，不保留逐日历史
- “开放权重”仅表示可下载或自托管，不等同于免费云端算力；额度、许可证与截止时间以来源页为准
- 新闻列表可用 `↑` / `↓` 切换正文；顶部板块和可见按钮支持方向键导航，`Enter` 或空格执行
- 窗口透明度调节
- 黄色、蓝色、无色、深色四套半透明主题
- 鼠标进入窗口时自动增强可读性，离开后恢复设定透明度
- 窗口置顶
- 左、右、上边缘自动隐藏，鼠标触碰后弹出
- 数据保存在 `%APPDATA%\轻笺\data.json`
- AI API Key保存在Windows凭据管理器，不写入便签数据文件

## AI总结服务

面试复盘和会议总结默认调用 Step Plan 的 OpenAI 兼容接口：

```text
Base URL: https://api.stepfun.com/step_plan/v1
Model: step-3.5-flash
Reasoning effort: low
```

首次使用时需要在“设置”中填写 Step Plan API Key 并测试连接。摘要和信息提取默认
使用低推理强度，以降低等待时间和额度消耗；长转写稿仍按段分析后合并。
设置页会根据 Step Plan 接口自动提供 `step-3.7-flash`、`step-3.5-flash-2603` 和
`step-3.5-flash` 模型选择；悬停模型可查看用途说明。推理强度支持 `low`、`medium`
和 `high`，悬停及选中后均会显示适用场景。其他 OpenAI 兼容接口仍可手动填写模型 ID。

## 运行

运行环境：Windows 10/11、Python 3.8 或更高版本。建议将项目克隆到 D、E 等非系统盘。

```powershell
git clone https://github.com/zhulvglos/QINGJIAN.git
cd QINGJIAN
```

双击 `run.bat`，或在当前目录执行：

```powershell
python main.py
```

贴边隐藏的使用方法：将主窗口或录音转写窗口拖至当前屏幕左侧、右侧或顶部，鼠标离开窗口后即隐藏。轻笺会动态识别外接屏、负坐标工作区和显示器拔插，鼠标触碰对应屏幕边缘即可恢复。

设置中的“界面字号”提供紧凑、标准和较大三档，作为显示器 DPI 自动缩放之外的个人字号倍率。主窗口和录音转写窗口会分别按照当前所在显示器的 DPI 等比调整窗口、字体、按钮和间距；跨屏拖动后自动重新适配。字号修改后通过托盘“刷新轻笺”生效。录音转写窗口为非模态窗口，录音期间主界面仍可拖动、切换和编辑。

## 可选语音组件

录音依赖由 `install_voice.bat` 安装到项目内的独立环境。SenseVoice 使用另一套完全隔离的环境，位于：

```text
<项目目录>\runtime\sensevoice_env
```

由于 Windows SentencePiece 可能不兼容中文路径，安装程序会在项目所在盘符的根目录建立
英文目录映射 `LightNoteSenseVoice`。它指向本项目，不复制模型、不占用双份空间。模型、缓存、
临时文件均保存在项目所在的非系统盘。需要重建独立环境时运行 `install_sensevoice.bat`。

模型权重和本地虚拟环境不进入 Git 仓库。请从模型官方来源准备 `SenseVoiceSmall`、
`fsmn-vad` 和 `campplus-speaker`，并分别放入 `<项目目录>\models` 下的同名目录。

## 测试

```powershell
python -m unittest discover -p "test_*.py"
```

进入笔记的“AI面试复盘”，选择“我的麦克风”
以及实际播放会议声音的耳机/扬声器，再点击“开始录音”。两路音频分别保存在
`%APPDATA%\轻笺\recordings`，点击“停止并转写”后才开始本地识别。
麦克风和会议回环分别由独立录音子进程负责；Windows音频驱动异常时主界面仍会保留，
错误详情写入对应录音目录下的 `recording.log`。录音中会显示两路是否收到数据；
其中一路为空时仍转写另一条有效轨道，只有两路均为空时才终止转写。
完整会后转写默认使用 SenseVoice-Small + FSMN-VAD；麦克风轨标记为“我”，会议声音通过
CAM++ 聚类标记为“会议方1、会议方2……”；OpenCC 后处理统一输出简体中文。
旧版 faster-whisper 已移除；轻笺当前仅使用 SenseVoice-Small 进行本地转写。
提问助手可在设置中选择“自动（StepAudio优先）”“仅StepAudio在线”或“仅SenseVoice本地”。
自动模式只上传本地VAD确认的会议方语句；完整录音及完整会后转写不会上传。
设置页分别提供“测试LLM”和“测试StepAudio”：前者验证总结/回答模型，后者用程序生成的
短静音音频验证 StepAudio 接口、API Key 与额度，不用于评价语音识别准确率。

## 当前边界

- 退出应用后不会提醒；后续可增加托盘驻留和开机启动。
- 提醒需要轻笺保持运行；关闭主窗口后会驻留系统托盘继续调度。
- Windows系统通知不可用时自动回退为应用内提醒。
- Windows 多显示器、主屏左侧负坐标、显示器热插拔和 Per-Monitor DPI 已适配；特殊显卡驱动组合仍建议实机验证。
- 语音设备名称和可用回环端点取决于 Windows 驱动；首次使用需手动确认所选耳机/扬声器。
- 完整转写仍在录音结束后生成，不提供逐字实时字幕；提问助手只显示本地检测到的候选问题。多人标签为声纹聚类结果，不识别真实姓名，短于30秒或多人重叠讲话时准确率会下降。
